최종 수정: 2026년 10월 15일

이 방침은 Simple Task Calendar Windows 데스크톱 앱에서 처리하는 데이터와 Google 캘린더 연결에 적용됩니다. 본 안내 홈페이지는 GitHub Pages로 제공되며, 홈페이지 방문 과정의 데이터 처리는 GitHub 개인정보처리방침도 적용됩니다.

1. 처리하는 데이터와 목적

  • 로컬 일정·할 일: 제목, 설명, 날짜·시간, 반복 정보, 완료·중요 표시 등을 일정 표시와 관리에 사용합니다.
  • Google 계정 정보: Google 계정 식별자와 이메일 주소를 연결 계정 확인 및 인증에 사용합니다.
  • Google 캘린더 목록: 캘린더 식별자, 이름 및 접근 권한 등 목록 정보를 동기화할 캘린더 선택에 사용합니다.
  • Google 일정 정보: 선택한 캘린더의 일정 식별자, 제목, 설명, 날짜·시간, 반복 정보, 위치, 주최자·참석자 정보 등 API 응답에 포함된 일정 메타데이터를 표시·편집·동기화에 사용합니다. 동기화 과정에서 Google API 응답 원문 일부가 로컬 캐시에 저장될 수 있습니다.
  • 인증 정보: OAuth 접근 토큰과 갱신 토큰을 허용된 Google API 접근 및 연결 유지에 사용합니다. Google 계정 비밀번호는 앱이 수집하지 않습니다.
  • 앱 설정과 동기화 상태: 알림 설정, 창·화면 설정, 동기화 이력과 미전송 변경을 사용자 설정 유지, 알림 및 오류 복구에 사용합니다.

2. Google 권한

<empty-block/>

Google 연결을 선택한 경우 다음 권한을 요청합니다.

  • openid: 연결 계정 식별
  • email: 계정 이메일 확인
  • https://www.googleapis.com/auth/calendar.events: 일정 조회·생성·수정·삭제
  • https://www.googleapis.com/auth/calendar.calendarlist.readonly: 캘린더 목록 조회

캘린더 선택은 앱의 동기화 대상을 정하는 기능입니다. Google이 부여하는 권한 자체가 선택한 캘린더에만 한정되는 것은 아닙니다.

3. 저장 위치와 보호

일정, 앱 설정 및 동기화 캐시는 사용자 PC의 로컬 데이터베이스에 저장됩니다. 갱신 토큰은 Windows의 운영체제 자격 증명 저장소를 사용하며, 접근 토큰은 인증 처리 중 메모리에서 사용됩니다. Google API와는 HTTPS로 통신합니다. 로컬 일정 데이터베이스 전체가 앱 자체에서 암호화된다고 보장하지 않으며, PC 계정·디스크·백업 보호는 사용자의 기기 보안 설정에 영향을 받습니다.

4. 전송·공유 및 사용 제한

Google 연결 시 앱은 인증과 일정 동기화를 위해 Google과 직접 통신합니다. 로컬 전용 일정은 Google 일정으로 등록하거나 이동하는 등 사용자가 Google 동기화 대상으로 지정하지 않는 한 Google 일정 동기화 대상으로 사용하지 않습니다.

현재 앱은 개발자 운영 서버로 일정이나 Google 인증 토큰을 수집하는 구조를 사용하지 않습니다. Google 사용자 데이터를 판매하거나 광고 타기팅, 신용 평가 또는 범용 AI·머신러닝 모델 학습에 사용하지 않습니다.

Simple Task Calendar의 Google API에서 받은 정보 사용 및 다른 앱으로의 전송은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 준수합니다.

사용자가 지원 이메일로 자료를 보내면 문의 처리에 필요한 범위에서 개발자가 해당 자료를 확인할 수 있습니다. 비밀번호·인증 토큰은 보내지 말고, 일정·로그 등에는 필요한 정보만 포함해 주세요. 문의 이메일과 자발적으로 제공한 자료는 문의 처리에 필요한 기간 동안 보관하고 목적 달성 후 불필요한 자료를 삭제합니다. 법령상 보존 의무가 있는 경우 해당 기간 동안 보관합니다.

5. 보관 기간과 삭제

로컬 데이터는 기능 제공을 위해 사용자 PC에 보관됩니다. Google 연결 해제 시 앱이 보관한 해당 연결의 인증 자격 증명을 삭제하고 Google 연동 로컬 데이터를 정리합니다. 미전송 변경이 있으면 화면의 안내에 따라 먼저 동기화하거나 사용자가 명시적으로 버리는 방식을 선택해야 할 수 있습니다.

앱에서 Google 연결을 해제하는 것과 Google 계정의 앱 접근 권한을 철회하는 것은 별개입니다. 권한 철회는 Google 계정의 서드 파티 연결 관리에서 할 수 있습니다. 연결 해제·권한 철회만으로 Google 서버에 이미 저장된 일정이 삭제되지는 않습니다.

로컬 전용 일정, 앱 설정, 수동 백업은 별도로 남을 수 있고 앱 제거만으로 모든 데이터가 삭제된다고 보장하지 않습니다. PC의 남은 앱 데이터나 백업 삭제 방법은 문의 이메일로 요청할 수 있습니다. 개발자는 사용자 PC의 파일을 원격으로 삭제할 수 없습니다.

6. 사용자의 선택과 문의

Google 연결 여부와 동기화할 캘린더를 선택할 수 있으며, 연결 해제 또는 Google 권한 철회를 통해 추가 접근을 중단할 수 있습니다. 데이터 열람·정정·삭제나 처리 관련 문의는 위 이메일로 보내 주세요. 로컬 데이터는 우선 앱과 PC에서 직접 관리할 수 있습니다.

7. 변경 안내

데이터 처리 방식이 바뀌면 이 페이지와 최종 수정일을 갱신합니다. 접근 목적이나 공유 범위의 중요한 변경은 적용 전에 앱 또는 관련 안내를 통해 알리고, 필요한 경우 별도 동의를 받습니다.
